## ⚠ Live Watchlist is organised by club, not by player

Each item is a **club to go and watch**, grouped by region. The players are listed comma-separated in the **Players To Watch** text column. **Scouting Status** is `Outstanding` / `Scheduled` / `Completed`. **Fixture Attending**, **Date** and **Attending** are filled in when a game is booked.

So the brief's "create the player on the Live Watchlist and set Club / Position / Notes" doesn't fit this board. Proposed rule (needs confirming):

1. Find the item whose name matches the player's club (column B), using normalised names and aliases.
2. **Club found:** append the player to `Players To Watch` if he isn't already listed. Leave everything else alone.
3. **Club not found:** create a club item in a region group, with `Players To Watch` = player and `Scouting Status` = `Outstanding`. Region can't be derived reliably, so the sync will report it and skip unless a region is given.
4. Position and Notes have no column on this board, so they aren't written.
